# Security policy

## Reporting a vulnerability

**Please don't open a public issue.** Report it privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on the affected repository (Security tab → "Report a vulnerability").

We aim to reply within 7 days.

## What's in scope

The app keeps a YouTube session (cookies) on the user's device, and that session is as sensitive as a password. We especially want to hear about:

- anything that could leak the session cookie file or its contents,
- requests that send cookies to a host other than YouTube or Google,
- ways a web page or video could run code or read local files.

## Supported versions

Only the latest release of each app gets security fixes.
