# Code of conduct

Be decent to each other. That means:

- Criticise code and ideas, not people.
- Assume good faith, and ask before you assume.
- No harassment, slurs or personal attacks, and no posting anyone's private information.
- Keep it on topic in issues and pull requests.

Maintainers may edit or remove comments, lock threads, or block people who don't follow this. To report a problem privately, contact a maintainer through their GitHub profile.
